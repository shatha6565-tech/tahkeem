# tahkeem
تحكيم المسابقات


برنامج تحكيم لمسابقات حفظ القرآن الكريم على نمط فروع مسابقة الملك سلمان: شاشة للمتسابقة تختار فيها رقم النموذج، وشاشة للمحكّمة فيها عدّادات الفتح والتنبيه والتجويد مع صوت، وزر «حسبك»، وترتيب للنتائج بين عدة محكّمات.

## الملفات
- `index.html` البرنامج كاملًا.
- `riwaya/` نصوص الروايات الثماني من مجمع الملك فهد لطباعة المصحف الشريف، و`fonts/` خطوطها.
- `seed.json` النماذج وبنك الدراية، تُحمَّل من تبويب «النماذج».
- `firebase-config.js` إعدادات قاعدة البيانات.
- `firestore.rules` قواعد الوصول لقاعدة البيانات.

## التشغيل
بدون إعداد Firebase يعمل البرنامج على جهاز واحد. وللمزامنة بين المحكّمات:
1. أنشئي مشروعًا في console.firebase.google.com.
2. فعّلي **Authentication ← Anonymous**.
3. أنشئي **Firestore Database** وانسخي محتوى `firestore.rules` إلى تبويب Rules.
4. أضيفي تطبيق ويب وانسخي إعداداته إلى `firebase-config.js`.
5. أضيفي نطاق الموقع (مثل `اسم-الحساب.github.io`) في Authentication ← Settings ← Authorized domains.

## المصادر
نصوص الروايات وخطوطها من [Quran Data KFGQPC](https://github.com/thetruetruth/quran-data-kfgqpc) عن مجمع الملك فهد لطباعة المصحف الشريف.
